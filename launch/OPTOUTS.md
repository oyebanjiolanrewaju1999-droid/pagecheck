# Opt-out log (CASL record)

Canada's anti-spam law requires that you honour a withdrawal of consent
"without delay" and keep a record. Log every person who asks you to stop, then
never contact that address or business again — including follow-ups.

| Date | Business | Address / form | How they asked | Action taken |

| | | | | |

Rules:

- Remove the row from any future batch list the same day.
- Set `Outcome` to `Opted out` in `TRACKER.csv`; do not delete the row.
- Keep this file for at least 3 years (CASL record-keeping).
- A bounce is not an opt-out, but stop after **two** bounces to the same domain.
